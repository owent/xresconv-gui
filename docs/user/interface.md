# 界面操作

## 配置与条目

顶部工具栏用于打开和重载配置、查看详细设置。加载失败时保留已经加载的会话，错误写入日志，修正输入后可重新加载。

左侧树支持展开、收起、行选择和三态勾选。父分组半选表示部分可选子项已选中，不可选条目不参与全选。搜索只过滤可见内容，已选状态继续保留，运行时处理所有已选且符合输出条件的条目。

条目详情显示来源表格、scheme 或 DataSource。详细设置和输出矩阵用于调整工具、目录、协议、输出类型及各类型的重命名和输出目录。字段编辑提交后成为后端会话设置，运行参数以预览和本次运行所冻结的值为准。

## 预览与运行

预览显示转换命令、输出路径和冲突提示。转换使用参数数组或 JAR 的 stdin 协议，预览字符串用于查看参数。

开始后按配置执行转换前事件、Java 转换和转换后事件。并行度默认为 4，可在 1–16 范围设置。取消会停止派发并回收所属进程，等待完成后再加载或运行。

批量转换没有可靠逐条确认时，界面展示批次结果与已提交任务数。确定某条目的产物时，检查对应日志和输出文件。

## 自定义按钮和事件

使用启动参数加载选择器 JSON 后，界面显示自定义按钮，可切换匹配条目的选择、执行动作链或调用命名脚本。事件开关控制允许修改的转换前、转换后和日志事件，见[配置文档](configuration.md)。

脚本弹窗通过应用对话框显示，确认、取消与关闭回调按脚本约定处理。取消或会话重载后，失效回调不会作用到新会话。

## 日志

日志支持级别和文本筛选、虚拟滚动、复制及导出。复制处理界面持有的日志窗口，导出按当前筛选条件分页读取后端保留的日志。内存容量有限，导出不能恢复已淘汰的条目；需要完整持久化时配置 [log4js](configuration.md#文件日志)。

Java 诊断、后端故障、脚本错误和持久化异常进入运行日志。过载时显示跳过或丢弃数量。

## 显示设置

支持亮色、暗色、跟随系统、字号和字体，设置保存在应用配置中。

语言可选择跟随系统、English、简体中文、繁體中文、日本語、Deutsch、Français 或 Español。默认按系统语言偏好选择支持的语言，没有匹配时使用英文；例如 fr-CA 使用法语，zh-HK 使用繁体中文。手动切换立即生效并记住，重启后继续使用该选择，选回“跟随系统”恢复自动检测。

语言切换保留转换会话与选择。配置中的名称、路径、脚本弹窗内容及转换器原始日志保持原文；已有日志不因切换语言重新翻译。

Windows 桌面应用在读取本机字体前，通过 WebView2 原生接口允许当前应用来源的 LocalFonts 权限，因此打开字体设置无需重复点击权限确认。读取失败或 WebView 不支持接口时，使用预设字体和手动输入。普通浏览器预览仍遵循浏览器权限设置。
