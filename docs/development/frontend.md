# 前端

React 界面位于 `apps/desktop`，业务通信集中在 adapters，应用状态与组件位于 `src/app`。界面通过 Tauri 命令和事件连接后端，浏览器测试使用适配层替代原生能力。

## 状态和编辑

`session-store.ts` 管理配置快照、树、运行结果、日志与故障状态，事件按会话、运行及代际合并。启动重试和后端重建后重新取得有效快照，过期结果不覆盖新状态。

字段组件保存草稿，提交时调用后端设置接口，再使用后端确认值。配置重载、事件开关、输出矩阵和并行度均通过明确接口更新，避免只修改界面造成预览与运行不一致。

运行控件组织加载、重载、预览、开始与取消。后端 `reset` 保持内部接口语义，界面状态不通过重建窗口恢复。

## 树与日志

树使用可访问性组件和虚拟化，三态勾选来自后端选择语义。行点击、勾选、展开和焦点各有明确操作，搜索保留选择。组件测试覆盖键盘、大字号、长名称、空状态和筛选后操作。

日志按 seq 去重合并，虚拟窗口限制 DOM 和内存。复制读取前端持有窗口，导出分页读取后端保留窗口并应用筛选。ANSI 样式转换和用户脚本 style 限定为安全表现数据，日志文本不作为任意 HTML 执行。

## 显示设置与字体

主题、语言、字号和字体通过显示设置持久化，主题变量由 CSS tokens 管理。布局需在明暗主题、窄窗口、大字号与长翻译下验证。语言匹配、英文回退及目录扩展见[多语言](localization.md)。

Windows 本机字体枚举前调用 `allow_local_fonts`，原生实现见 [local_fonts.rs](../../src-tauri/src/local_fonts.rs)。使用 WebView2 profile 的 `SetPermissionState(LocalFonts, Allow)`，仅接受当前应用来源与 debug 配置的开发来源。权限完成后再调用 `queryLocalFonts`，失败时保留预设字体及手动输入。

原生回调在窗口线程注册，结果等待在阻塞任务执行，具有截止时间。前端枚举保留 Window 调用接收者。浏览器 preview 不能证明 WebView2 权限持久化，相关验证需要真实桌面 profile。

## 验证与资源

组件测试验证交互与状态，Playwright 三引擎验证生产前端，桌面 E2E 验证原生接口及实际通信。图标与素材见[图标资源](../brand/README.md)和[界面素材](../media/README.md)。
