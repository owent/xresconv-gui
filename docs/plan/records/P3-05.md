### 3. stdin-encoder.ts（P3-06，backend/convert）

- `encodeTaskLine(argv)`：含 `"` 不含 `'` → 单引号包裹；含 `'` 不含 `"` → 双引号包裹；两者都含/含 \r\n/空串 → 抛 `StdinEncodeError`（code/token/reason；是否走 argv 回退由调用方决定）；含空白 → 双引号；其余 bare。token 间单空格。
- `tokenizeStdinLine(line)`：Main.java:344-374 同形移植（引号剥除 + 空 token 丢弃），供 plan-builder 切原始片段。
- `buildArgvFallbackCommand(javaArgs, jar, taskArgv)`：不经 stdin 的逐任务 argv 路径。
- 测试内置独立 mini-parser（注明 Main.java:344-374 来源）做往返断言基准：中文/空格/单双引号/反斜杠/`$`/`(?i)` 正则/UNC 路径全过；不可编码输入三类抛错有断言。

### 4. java-runner.ts（P3-07 backend/guardian 适配，guardian/src 新增模块）

`runJavaBatch({javaArgs, jarPath, workDir, tasks, onLog?, deadlineMs?, signal?}) → {exitCode, signal, failedTaskCount, durationMs}`。

- `spawn("java", javaArgs.concat(["-jar", jarPath, "--stdin"]), {cwd: workDir})`（main.js:2121-2144）；任务行按序写 `line + "\r\n"`，`write` 返回 false 等 `drain`（背压）；写完 `stdin.end()`；tasks=[] 直接 end。
- stdout/stderr：StringDecoder(utf8) 拆包安全 + 半行缓冲按行抛 onLog；**完成判定只以进程 close 为准，data 事件不驱动派发**（BD-03 落实，BD-P2）。
- `failedTaskCount = exitCode`（xresloader 失败任务数累加约定，Main.java:399-411）。
- deadlineMs/AbortSignal → SIGTERM → 2s 宽限 → SIGKILL（BD-P8），reap 后分别拒绝 HardDeadlineError（复用 run-with-deadline 导出）/AbortError；SIGKILL 后 2s 仍无 close 兜底拒绝（防僵尸，对齐 runWithDeadline 策略）。spawn error → SpawnError 透传。
- 真实 JAR 集成测试 8 例全过：a 单行 const 任务 exit 0 且输出非空；b stdin 与 buildArgvFallbackCommand 直 argv 两路径输出逐文件 SHA-256 相同（const 转储经实测不含时间戳/路径，确定性成立）；c `空格 dir` 与 `quote'dir` 输出目录成功；d 坏 .pb → exitCode=1、stderr 经 onLog 到达；e 3 任务批次顺序执行日志条数 ≥3；另空批次 exit 0、abort→AbortError、deadlineMs=1→HardDeadlineError。
