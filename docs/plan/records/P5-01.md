## 设计

```mermaid
flowchart LR
  tj[packaging/targets.json<br/>22 目标] -->|targets.schema.json<br/>+ validateTargetSemantics| load[load.ts<br/>loadTargets/validateTargets]
  base[baseline.ts<br/>D1/D2 基线集合] -->|baselineKeys 精确集合相等| load
  load --> mtx[matrix.ts<br/>buildMatrix/artifactName]
  mtx -->|MatrixArtifact[] 按 targetKey 排序<br/>每行带 .sha256 sidecar 名| ci[CI-06 聚合 job<br/>集合相等比对 待接线]
  rm[runtime-manifest.json<br/>产物侧] -->|runtime-manifest.schema.json<br/>+ lintManifest| mval[load.ts validateRuntimeManifest]
  lint[lint.ts<br/>PK01 卫生 lint] --> mval
```

- **targets.json（22 目标）**：Windows x64/arm64 × bootstrap/offline（webview2-embed-bootstrapper / webview2-offline-installer，WebView2 下限 120.0.0）；macOS x64/arm64 × 两变体（system-only，无 webview 版本号，门为 osVersionRange ≥13.5，D5）；Linux bootstrap = D2 六发行版（ubuntu-22.04/24.04、debian-12/13、fedora-43/44）× x86_64/aarch64（webkitgtk-system，下限 2.38）；Linux offline = x86_64/aarch64 自含包（webkitgtk-bundled，无 distro）。全部 `nodeVersion: "24"`。
- **语义校验（schema 之上的 PK01 闸，load.ts `validateTargetSemantics`）**：禁架构精确匹配表 FORBIDDEN_ARCHES=[ia32, x86, armv7l, armv7]（D1，不误伤 x86_64/aarch64）→ 域成员检查（os/variant/arch/distro/webviewStrategy 未知即 UNKNOWN_TARGET）→ 每 os 一致性（INCOHERENT_TARGET：windows/macos 禁带 distro、arch 限 x64/arm64；windows variant↔webviewStrategy 配对且必须声明 WebView2 下限；macOS 必须 system-only 且 minimumWebview=null；linux bootstrap 必须带 distro+webkitgtk-system，offline 必须无 distro+webkitgtk-bundled）→ 重复目标（同 os/distro/arch/variant）DUPLICATE_TARGET → 与 `baselineKeys()` 精确集合相等（缺 MISSING_TARGET、多 UNEXPECTED_TARGET）。所有失败抛带稳定机器码的 `PackagingError`（11 个 code）。
- **命名与矩阵（matrix.ts）**：`xresconv-gui-<version>-<os>-<distro?>-<arch>-<variant>.<ext>`；distro 段仅 linux bootstrap 出现；格式映射 windows→nsis(exe)、macos→dmg、linux bootstrap→deb/rpm（fedora-* 为 rpm）、linux offline→appimage（AppImage）。version 受 semver 模式闸（拒绝路径分隔符/空串/v 前缀等，INVALID_VERSION）。`buildMatrix` 产出按 targetKey 排序的可序列化 MatrixArtifact 行（含 sha256 sidecar 名），名字冲突即 DUPLICATE_TARGET。
- **清单卫生 lint（lint.ts，PK01 防泄漏）**：递归扫描任意 JSON 值；规则 = 密钥形态键名（pass*/secret/token/api[-_]key/private[-_]key/credential，空值与 `<redacted>` 占位放行）+ 密钥值形态（PEM 私钥块、AWS AKIA、GitHub ghp_*/github_pat_*、Slack xox*、JWT）+ 开发机绝对路径（Windows 盘符、UNC、`/Users/`、`/home/`）；finding 带 RFC 6901 pointer、规则 id、截断摘录。`validateRuntimeManifest` 默认联动 lint（MANIFEST_LINT），`{lint:false}` 仅用于 schema 聚焦测试。
- **基线集合单一来源**：`baselineKeys()` 从 LINUX_DISTROS 等常量派生 22 键；targets.json 与其精确集合相等才放行——发行版清单调整只改 baseline.ts 一处，targets.json 不改即红。
