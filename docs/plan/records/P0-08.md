## 1. 配置解析（build_conv_tree 及调用者）

### 1.1 XML 解析器

- **没有真正的 XML 解析器**。`build_conv_tree(context, current_path)`（main.js:1192-1851）直接 `jdom = $(context)`（main.js:1198），即 jQuery 4.0.0（package.json `jquery: ^4.0.0`）的 HTML 解析（parseHTML → innerHTML）。
- 由此产生的行为合同：
  - 标签名大小写不敏感，源码统一 `dom.tagName.toLowerCase()`（main.js:1225）；属性经 jQuery `.attr()` 读取，HTML 语义下大小写不敏感。
  - 元素文本经 `$(dom).html()` 读取（如 main.js:1208、1226），HTML 实体会被解码。
  - HTML 解析不支持非 void 元素自闭合：`<tree .../>` 会被当作未闭合开放标签，后续兄弟被吞为子节点 [推断：HTML5 解析语义，未执行验证]。
  - `<script>` 是 raw-text 元素：`<gui><script>` 内 JS 可含 `<`、`>`、`&`，但不能含字面量 `</script`；`<set_name>`/`<on_before_convert>` 等非 script 容器内的 JS 若含 `<字母` 序列会被截断 [推断]。
  - 只识别**根的直接子元素**：`jdom.children("include"|"global"|"category"|"gui"|"list")`（main.js:1207、1224、1464、1467、1610），更深层同名标签不生效。
- 顶层入口：`on_load_conv_list_file`（main.js:2651-2668）→ `reset_conv_data()`（main.js:926-953）→ `conv_data.file_map[clf.path]=true`（main.js:2661）→ `build_conv_tree(clf.data, clf.path).then(show_conv_tree)`（main.js:2663-2666）。文件统一按 UTF-8 读取（main.js:959；include 文件 main.js:1802-1812 Buffer.concat→toString 默认 utf8）。
- `--input` 启动文件经 `location.search` 正则 `input=([^\\&\\#]+)` 提取并 `decodeURIComponent`（main.js:2757-2764），对应 setup.js 的 `encodeURIComponent`（setup.js:169-170）。
