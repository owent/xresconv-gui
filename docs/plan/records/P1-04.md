## 实施结果

- 新增 `packages/backend/bin/health-check.mjs`：一次性握手行（role/node/pid/protocol_version）。
- 重写 `packages/guardian/bin/health-check.mjs`：以 `process.execPath` 启动 backend（同一 Node 二进制，§6.1），外部硬截止默认 5000ms（`XRESCONV_BACKEND_DEADLINE_MS` 可覆盖，供测试），截止 SIGKILL + 1s 回收宽限；解析 backend 首行 JSON 并输出合并握手 `{ok, role:"guardian", pid, node, backend:{…}}`；backend 异常/超时/非法 JSON 均以非零退出 + stderr 结构化诊断，不伪造成功。
- backend 入口解析顺序：`XRESCONV_BACKEND_ENTRY` env → 相对本文件的 `../../backend/bin/health-check.mjs`。
- 壳侧 `get_backend_health` 不变（仍只启动 guardian 入口并解析首行）；壳截止由 5s 上调至 15s，避免 guardian 已报告失败时被壳抢先杀掉丢失诊断。
- `packages/contracts/schema/node-health.json` 新增为握手行唯一契约源（guardian/backend 角色、递归 `backend` 嵌套）；`yarn generate` 生成 `NodeHealth` 类型，App 与 guardian 测试共用；Ajv strict 校验合并握手。
- `apps/desktop/src/App.tsx` 显示 `guardian ok … · backend ok · pid N · protocol v1`；组件测试与桌面 spec 同步更新。
