## 新发现与决策（并入规则）

- Yarn 4 install 在非交互 shell 下偶发 `onCancel` 崩溃（疑似交互提示路径）；重跑即过。CI 需保证非交互（`CI=1`）。
- vitest 5 将 `vite` 列为必需 peer：各用 vitest 的 workspace 显式声明 `vite` devDependency 后 YN0002 警告消除。
- 裸 `(?i)` 前缀不是合法 JS RegExp（旧选择器若使用该写法会走"精确匹配"回退）；合法内联写法为 `(?i:...)`。已写入 compat-service 测试。
- Ajv strict 模式拒绝 union `type: [...]`；`details` 字段放宽为 `type: "object"`（样例仅对象形态；字符串/标量详情不作为契约承诺）。
