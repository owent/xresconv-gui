## 目标

环境变量样本、离线运行）与 PK07（无全局 Node/npm、安装目录中文/空格/只读）

## 关键调研结论（实施前实测，非猜测）

1. **裸包名缺口**：executor 的 `createRequire(configure_file)` 锚定用户配置
   目录（BD-S1）；生产环境用户配置在任意路径，`require("adm-zip")` 无法
   解析到应用捆绑模块——P2-02 测试通过仅因锚点设在仓库内。必须有回退锚点。
2. **node_modules 内禁止类型剥离**：Node 24 对 `node_modules` 下的 `.ts`
   报 `ERR_UNSUPPORTED_NODE_MODULES_TYPE_STRIPPING`（首轮 staging 复制 TS
   源实测失败）。**发行布局的 workspace 代码必须打包为纯 JS**（P5-02 沿用）；
   同时 `@xresconv/contracts` 的 `schema/*.json` 是 validators 运行时
   `require.resolve` 动态定位的资源，必须落位。
3. **vm 沙箱无 `process` 全局**：旧版同样用 `vm.createContext`（main.js
   :191/589/1708/2326），`process` 不进沙箱；脚本读环境变量的真实路径是
   `require("node:process").env`（README 未提及，首轮测试用裸 `process`
   ReferenceError 实测发现）。

## 实施结果

### executor.ts：回退锚点兼容层

- env `XRESCONV_SCRIPT_MODULE_DIRS`（path.delimiter 分隔的 anchor 目录
  列表，每进程惰性解析并缓存）声明发行捆绑模块目录。
- `makeRequire` 包装：锚定解析先跑；**仅裸包名**且"找不到的就是这个说明符
  本身"（code=MODULE_NOT_FOUND 且 message 含该 id——模块找到但其内部依赖
  缺失时不得回退，避免掩盖坏包）才依次回退。相对/绝对/`node:` 说明符不
  回退（BD-S1 不变）；用户配置旁 node_modules 优先于捆绑目录。
- `require.resolve` 同样包装（显式 `paths` 选项时不回退）。env 未设置时
  行为与之前完全一致（既有 40 例 script-host 测试不变）。

### script-worker.ts：workerEnv 环境策略接线（P2-04 环境策略落地）

- `ScriptWorkerPoolOptions.workerEnv?: Record<string, string|undefined>`
  覆盖注入 worker spawn 环境（undefined 删键）。发行接线：backend 按
  runtime manifest 注入 `XRESCONV_SCRIPT_MODULE_DIRS`（P5-02 组装）。

### release-layout.test.ts：staged 发行布局实测（4 例）

staging（beforeAll，有界 180s）：临时目录建 `安装 目录/`（中文+空格）→
复制 `process.execPath` 为 `runtime/node.exe`（单份 Node）；esbuild 0.28.2
打包 `worker-main.ts` 为纯 JS bundle（@xresconv workspace 包内联，ajv/log4js/
minimatch external）+ 生成保留 fd2 控制台重定向的 entry shim；
`@xresconv/contracts` 的 schema 落位；npm 闭包（adm-zip/compressing/koffi
与 external 种子，50 包 6.8MB，含 `@koromix/koffi-win32-x64` 原生二进制；
缺失的平台 optionalDependencies 跳过）从仓库 node_modules 递归复制；
spawn 前整树置只读（afterAll 恢复后清理）。用户项目在**安装树之外**。
环境重建为最小集：PATH 仅 System32，无 npm_*/NODE_PATH——包管理器/网络
补包无从发生。

| 场景 | 结果 |
| --- | --- |
| a. staged node.exe 启动 worker、握手、execPath 即 staged 副本 | 通过（无全局 Node 证据） |
| b. 内置 node:path + 相对 ./helper.js + adm-zip 中文条目 round-trip + compressing gzip FileStream/UncompressStream round-trip + koffi 原生加载 + 环境变量样本 + npmEnvVisible=0 | 通过（SC04 发行布局全链） |
| c. 负对照：未注入回退锚点时 `require("adm-zip")` 按 MODULE_NOT_FOUND 失败 | 通过（证明 b 的成功来自回退机制而非环境泄漏） |
| d. 用户配置旁伪造 adm-zip 胜过发行捆绑 | 通过（BD-S1 锚定优先） |

## 边界记录（不冒充完整保证）

- "无网络"是机制级证据（无包管理器调用路径、无网络代码路径、环境无 npm
  配置），非抓包证据；PK07 完整验收（真机移除全局 Node/开发工具、安装器
  产出物）属 P5-02/P5-10。

  旧 GUI 也无此样本，记录在案不阻塞。
