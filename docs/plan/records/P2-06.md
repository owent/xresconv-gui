## 目标

SC06：脚本 `alert_warning`/`alert_error` 的回调次数/顺序与旧版一致（yes→yes()→on_close()、
no→no()→on_close()、ESC/关闭无回调）；**合法回调不提前销毁**（invocation 结束后应答仍
触发）；**过期回调不执行**（重复点击、worker 失效后的迟到应答、代际切换后的旧弹框）；
按 BD-06 修复"ESC 关闭不回调造成的挂起"——关闭/到期必须收尾，不允许永久 pending。

## 实现（两侧注册表，guardian 为失效策略单一 owner）

### worker 侧（script-host/src/worker-main.ts）

- `dialogCallbacks: Map<token, {callbacks, invocationId, createdAt}>`：登记带注册上下文
  （诊断可关联 invocation）。
- 应答处理：先取后删（**exactly-once**，重复应答第二次直接拒绝 + fd2 诊断
  "unknown/stale token"）；yes/no 顺序与异常跳过 on_close 语义不变（P2-03 已有）。
- **不**随 invocation 结束失效（旧版 modal 晚于脚本结束仍可点，SC06 明确要求）。
- choice null/缺失 → 无回调，仅最终化 + fd2 诊断（含驻留时长，BD-06 收尾可见性）。
- `alert_error` 现在也登记空回调（旧版无回调）：应答到达静默最终化，不再产生
  "unknown token" 噪音。
- worker 进程退出时注册表随进程消亡；留存上限由 guardian 兜底（见下），worker 不
  自建定时器（单一 owner，避免两侧策略漂移）。

### guardian 侧（guardian/src/script-worker.ts）

- `pendingDialogs: Map<token, {slot, env, createdAt, answered}>`：handleDialogRequest
  登记；`respond()` 在 `answered`/注册表被移除/`slot.killing`/`slot.exited` 任一条件下
  丢弃应答（过期调用不执行）。
- `dialogTimeoutMs` 选项（默认 30min，**BD-W10**）：懒启动 unref 清扫器
  （interval=clamp(timeout/2, 25ms, 60s)，注册表空即停）；过期条目按 ESC 语义补答
  null（worker 最终化，无回调）+ `onDialogInvalidate(env, reason)` 通知 UI 关闭。
- `handleExit`：worker 死亡 → 其在途弹框全部失效（不向死进程应答）+ 通知 UI。
  覆盖超时销毁（BD-W3）、fault 丢弃、pool shutdown 全部路径（它们都经 exit）。
- `dismissPendingDialogs(reason): number`：代际切换（UI reload/会话重建）显式收尾，
  逐个按 null 应答 + 通知，幂等，返回条数。属应用层入口（P4/UI 壳在 reload 时调用）；
  ConversionSession 只透传 `onDialogInvalidate` 回调，不主动 dismiss（池为调用方共享，
  BD-O6）。

## BD 新增

- **BD-W10 未应答弹框有界留存（默认 30min）**：旧版 modal 无限期挂着；新架构
  pool/worker 长命，无界留存 = 闭包泄漏。过期按 ESC 语义应答 null（无回调，
  与旧版 ESC 行为一致）并通知 UI 关闭。属有意收紧，交互上 30min 足够宽；
  可用 `dialogTimeoutMs` 调整。

## SC06 验收映射（全部本机实测）

| 场景 | 结果 | 证据 |
| --- | --- | --- |
| yes → yes()→on_close() 各一次按序 | 通过 | worker.test.ts `l`（order=yes,close）、guardian `c` |
| no → no()→on_close() | 通过 | worker `l` 同路径（choice 分支对称） |
| ESC/关闭 → 无回调且最终化（BD-06 修复） | 通过 | worker `l`（choice null 无回调 + wall-clock 收尾）+ fd2 最终化诊断；guardian `a`（TTL 兜底应答 null） |
| 重复点击/重复应答 → 只触发一次 | 通过 | worker `r`（第二次 stale 拒绝） |
| 脚本结束后回调（合法回调不提前销毁） | 通过 | worker `q`（complete 后应答仍按序触发） |
| worker 失效后点击 → 不执行 | 通过 | guardian `b`（WORKER_TIMEOUT 销毁 → invalidate → 迟到应答丢弃、池补员可用） |

| 未应答弹框不永久 pending（BD-06/BD-W10） | 通过 | guardian `a`（150ms TTL 过期收尾） |
