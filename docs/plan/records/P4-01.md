## 桥接能力保留与 StrictMode 约束

P1 骨架的四项壳能力迁入 `src/adapters/tauri.ts`（get_app_info / get_cli_matches / get_backend_health / XML 文件选择，取消返回 null），组件只依赖该适配层，测试继续按 mock `@tauri-apps/api` 的方式替换。适配层对同命令做在途 Promise 去重：StrictMode 双挂载下 get_app_info/get_cli_matches/get_backend_health 各恰好 invoke 1 次（App.test.tsx 断言调用计数）；Promise 结算后条目自动清除，"重载配置"会发起新探测（测试断言重载后 get_backend_health 计数=2）。挂载副作用带 cancelled 清理，卸载后不回写状态。
