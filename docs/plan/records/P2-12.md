2. 新增 envelope kind 或新增 schema 文件属向后兼容扩展，不破坏冻结；须
   同步 schema-freeze.test.ts 的 FROZEN_SCHEMAS 清单与 records。
3. `src/generated/` 永不手改；守卫测试逐 schema 重编译比对，漂移即失败
   （本切片实测 P2-05 的 script-invoke 演进与生成物零漂移）。
4. 内部协议面（matcher worker、guardian↔backend fork IPC）不进跨角色
   契约集，但其握手同受 protocol_version 约束。
