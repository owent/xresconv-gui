## 已确认问题与处理

| 问题 | 证据与影响 | 修复和验证 |
| --- | --- | --- |
| `work_dir` 是普通文件时错误派发 | 最新提交只用 `existsSync` 判定。新回归在修复前得到 `succeeded`，假 Java runner 被调用；真实进程会因 cwd 无效而失败 | 改为 `statSync`，区分缺失、非目录、读取失败；失败任务数按计划任务计。`run.test.ts` 的文件路径用例先红后绿，原缺失目录用例保持通过 |
| Windows ACL 预检泄漏 SID 缓冲 | `ConvertStringSidToSidW` 为两个 SID 分配内存，原实现只释放 DACL/描述符。微软[API 文档](https://learn.microsoft.com/en-us/windows/win32/api/sddl/nf-sddl-convertstringsidtosidw)要求对返回的 SID 调用 `LocalFree` | 在成功及第二个 SID 转换失败路径释放已分配 SID；Windows Cargo fmt/test/clippy 通过。未用单测声称证明原生分配释放，仍需离线 VM 运行时验收 |
| 根目录混入生成负载 | `f5b9a87` 新增的 `probe_style` 是未被引用的 917 字节转表输出，内容带开发机绝对路径 | 删除误提交文件；检查工作树与引用 |
| lint 警告及发行文档漂移 | 最新提交有无效 Biome 抑制；IPC 测试有两处旧式 `hasOwnProperty`；主计划存放过期状态快照，README/来源索引仍混用安装器与当前便携归档描述 | 清理抑制与测试表达式，lint 零告警；压缩主计划状态，更新用户下载说明、Agent 入口、文档索引和来源索引 |
