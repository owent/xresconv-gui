## BD 差异清单更新

- **BD-S18（新）** spawn/定时器等异步回调内未捕获异常：旧版传递至渲染进程
  导致 GUI 白屏（README"已知问题"）；新架构 worker `uncaughtException` 记
  fd2 诊断并存活，该 invocation 因有界超时按 rejected 结算（BD-W3 销毁
  补员），其余调用与 GUI 不受影响。属缺陷修复型差异，切换说明需告知
  "try+reject" 旧建议不再必要（但仍是好实践：异常回调所在 invocation
  永远不会 resolve，只能等超时）。
- BD-S1~S17 维持既有记录（P2-03/P2-05），本切片未发现新差异。
- 结论：**公开合同内真实脚本样例无未解释差异**，G2 的脚本侧阻塞项清零
  （剩余 G2 项见 P2-12）。
