## 剩余边界与已知工具问题

- G2/G3 仍是部分实现：桌面只连接 P1 健康探测，尚未以长期独立 guardian/backend 接入转换；Windows Job Object/POSIX 进程组、backend/guardian 崩溃恢复、完整 reset/close 未实现。当前直接子进程 close 证据不是进程树清理证据。
- NodeMirror、session/revision 完整协议、selected_nodes、跨调用对象别名/模块缓存及按钮 data 编排仍需按 P2 合同实现；当前快照修复不等于这些兼容要求已完成。共享 pool 的会话事件仍为单消费者。
- matcher RegExp 与 XML 大解析尚未移入可终止 helper；读取字节预算不能证明事件循环 CPU 上限。独立节点/脚本文本预算、100k 节点和持续日志风暴尚未验收。
- log4js 请求确认表示 appender 调用返回；最终 flush 以 shutdown 为准，异步磁盘错误、轮转/权限/磁盘满、过载完整持久化仍待系统验证。过载策略见 [日志合同](../03-domain-conversion.md)，不能声称无损。
- 六格式结果是同 JAR 两条输入路径对照；ue-json/ue-csv、完整旧 GUI 脚本兼容、多平台/安装、P4–P7 不在本次通过证据中。
- Yarn YN0086 来自已锁定 WDIO 上游 peer：`pbf3c36`、`p753606`、`p01a2f0`、`pda674e`（由 `yarn explain peer-requirements` 核实）；没有通过忽略/删除锁项掩盖。
- `@wdio/tauri-service` 1.4.0 的 external provider 在未启用可选插件时仍发焦点/清理告警，并出现其内部 shell 启动的 DEP0190。3 个业务断言通过，不视为“零告警”。本轮还确认它遗留一对 driver 进程；核对创建时间、父 PID、端口后只终止本轮 PID 82836/55392，复查二者已消失。任务前已有六对驱动未动；上游服务的自动清理仍需后续独立修复。
