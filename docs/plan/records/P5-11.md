## 2. 实现

- `matrix.ts`：`portableBundleTarget`（macOS→`app`、linux offline→`appimage`、安装器目标抛 `NO_PORTABLE_FORMAT`）、`portableArtifactName`（macOS `.app.zip`）、`portableArtifactNames`（验证范围精确 4 项，排序确定性）。
- `package-cli.ts`：`--portable`（要求显式单 `--variant`；格式覆盖 + macOS 分支经 `selectArtifact(bundle/macos, ".app")` + `ditto -c -k --sequesterRsrc --keepParent` 压缩；`zipMacAppBundle` 仅 darwin 宿主可达）；tauri build spawn 超时 30→45 分钟（mac 冷缓存 release 构建余量）。
- `verify-portable.ts`（+ `scripts/verify-portable.ts` 薄入口、`yarn verify:portable`）：sidecar/SHA-256 → 解包（ditto / `--appimage-extract`，均在构建 job 内执行位完好）→ 定位 `runtime-manifest.json` → schema 校验 + 身份逐字段比对（含本次 commit）→ **manifest.files 全量存在 + 大小 + SHA-256**（与 `verifyReusableLayout` 同强度，证明打包未损坏负载）→ 包内 `runtime/node --version` 原生探针（架构正确性直接证据）→ macOS 验 Info.plist 含 `LSMinimumSystemVersion`/13.5 与主二进制；Linux 验 `AppRun` 与 `usr/lib/libwebkit2gtk-4.1.so.0` 自含闭包。
- `portable-build.yml`：4 个构建 job（rust-cache 按 OS/arch 分键）+ `verify-matrix` 聚合（`verifyReleaseArtifacts` 精确集合 + 边车哈希；CI-06 语义，无 release 写权限）。Action 全 SHA 固定（复用 P5-09 已核验版本）。

### 缺陷修复：Linux 发行布局自定位（`guardian.rs`）

壳侧候选此前只有"exe 同级 + `../Resources`（macOS）"，而 deb/rpm/AppImage 的 resources 在 `usr/lib/<productName>`，无候选命中——**P5-05/P5-06 的"启动冒烟"实际走的是开发态回退**（launch cwd 恰为仓库，PATH node + 相对路径命中 dev guardian），属真实缺陷。修复：候选补 `../lib/<productName>`（deb `/usr/bin`→`/usr/lib/xresconv-gui`；AppImage `$APPDIR/usr/bin`→`$APPDIR/usr/lib/xresconv-gui`），Rust 回归 `release_layout_candidates_cover_linux_resource_dir`。P5-05/P5-06 冒烟结论据此降级为"未验证发行自定位"，其构建产物证据不受影响。
