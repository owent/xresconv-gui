## 实施设计与验收标准

用户已授权审查修复、补测试及研究尺寸优化，并允许裁剪语言。保留 bootstrap zip / offline tar.zst 和系统 Evergreen 优先策略。

1. Windows 归档使用 `build/` 下每次独立暂存目录；tar 只接收相对文件名，避免 GNU/bsdtar 选项与盘符差异；保持无压缩 tar → 外部 zstd 文件压缩，失败不降级。校验成功后才替换归档，失败保留先前有效产物及其校验文件，清理本次暂存。
2. ZIP 避免 PowerShell 路径拼接，覆盖含单引号路径及隐藏文件。失败、超时、压缩器缺失、损坏输出、源文件缺失须有回归测试。
3. CI 工具探测明确检查原生命令退出码，不依赖 PowerShell `catch` 捕获非零退出。
4. 尺寸研究比较完整语言与十种语言（en-US、zh-CN、zh-TW、ja、ko、de、fr、es、pt-BR、ru），以及 zstd L19、长距离匹配和更高级别；同负载、同工具、记录字节数与耗时，解包核验。
5. 语言裁剪只涉及已识别的 Locales 语言包，保留 ICU、字体/渲染/PDF/媒体/原生模块及许可；不得修改下载缓存。微软要求携带全部文件，裁剪没有官方支持承诺：本轮虽完成固定版本真实运行验证，仍保留 `all` 为默认；显式 `--webview-locales=mainstream` 启用十语言。

风险与回退：不改变归档格式或运行时分发形态；压缩参数可退回 L19；语言实验独立于原始缓存，任何未验证裁剪都不进入默认发行。跨平台/干净离线机器验收单列，不以本机测试替代。

RED 阶段：归档 7 失败/4 通过；CI 探测 3 失败/2 通过；Rust 运行时覆盖 1 失败；语言复制占位实现 5 失败/1 通过。GREEN 阶段均通过，另补截断流、ZIP 失败和真实 ZIP 往返。共新增 26 项 TypeScript 测试、1 项 Rust 测试。

发布边界：文件系统不能原子替换“归档+边车”两个文件；本实现先使旧边车失效，再替换归档，最后由 CLI 写新边车。最终 rename/边车写入失败时可能留下无边车归档，聚合必须拒绝；不会把旧边车当成新文件校验。上述“保留旧产物对”适用于复制/压缩/校验失败阶段。

## 尺寸实验与选择

环境：Windows x64，Node 24.21.0，Fixed Version 154.0.4258.37；系统 bsdtar 3.8.8/libzstd 1.5.7，外部 zstd 1.5.7。输入来自任务开始时的完整 offline 包，同一目录分别创建 tar 和 7z；原始 tar 815231488 字节。裁剪只移除 148 个语言资源、121830225 字节（116.19 MiB）；ICU/二进制不变。

| 资源 | 方法 | 字节 | MiB | 较全语言 L19 | 单次压缩秒数 |
| --- | --- | --- | --- | --- | --- |
| 全语言 | zstd -19 -T0 | 275350176 | 262.59 | 基线 | 62.27 |
| 全语言 | zstd -19 -T0 --long=27 | 264539709 | 252.28 | -3.93% | 97.93 |
| 十语言 | zstd -19 -T0 | 254764784 | 242.96 | -7.48% | 111.45 |
| 十语言 | zstd -19 -T0 --long=27 | 243664078 | 232.38 | -11.51% | 155.25 |
| 全语言 | 7z LZMA2 -mx=9 -mmt=on | 220877385 | 210.65 | -19.78% | 132.16 |
| 十语言 | 7z LZMA2 -mx=9 -mmt=on | 202530885 | 193.15 | -26.45% | 94.02 |

耗时是开发机单次观察；部分压缩与测试/编译同时进行，不能用这列作严格速度排名。体积为实际文件字节，四个 zstd 输出均通过 `zstd -t`；7z 完整性与本机系统 tar 兼容性另验证。历史 L22/7z 数字语料不同，不与本表混算。

选择：默认保留 tar.zst 和全语言，采用 long=27；十语言作为明确可选策略，命令：

```powershell
corepack yarn package:windows --variant=offline --webview-locales=mainstream
```

需要遵循微软完整文件集分发建议时使用默认值或显式 `--webview-locales=all`。参数不适用 Linux/macOS/bootstrap 单变体时直接报错，不能静默忽略。包内 `webview2-runtime-policy.json` 记录实际策略与删减数。

进一步优化建议：7z 是本轮体积收益最高的候选，保留全语言已小于裁剪后的 zstd。但当前发布矩阵只接受 zip/tar.zst/DMG/AppImage；本轮不改变公开资产格式，需先完成旧 Windows 解压与格式迁移验收再启用 7z。L22/更大窗口会增加时间与内存，未作为默认。Node small-icu 改变脚本 Intl 能力且要求维护自定义 Node 发行，未采用；静态引用不能证明脚本动态 require 的依赖可删。Linux WebKitGTK 闭包压缩/语言资源、macOS DMG 与 Rust profile 优化需在原生目标重新测量，没有跨平台实测收益声明。
