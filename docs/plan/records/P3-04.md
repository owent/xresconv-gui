## 行为差异（BD-M）

- **BD-M1（缺陷修复，P0-08 §1.4 / 附录 B1）**：旧 `check_matrix_rule` tags 分支引用不存在的自由变量 `output`（main.js:1015），带 tag 限定的矩阵规则必抛 ReferenceError，tag 限定功能实际不可用。新版 tags 按 classes 同一交集规则实现（复用 `matchClasses`，main.js:1020-1028 语义），tag 限定恢复可用。
- **BD-M2（返回类型正规化）**：旧 regex 分支返回 `input.match(re)` 的数组/null（main.js:142），真值语义；新版一律返回 boolean（`RegExp.test`），真值判定不变，类型更窄。
- **BD-M3（diagnostic 途径）**：旧版编译异常直接写 GUI 错误日志（`logger_append_error_message`）；新版改为注入回调、默认 no-op。日志内容（两条：规则无效提示 + 异常对象）与触发时机不变。
- **BD-M4（glob 空输入容错）**：旧 glob 分支 `glob_rule.match(input)` 对 undefined 输入会抛 TypeError（实际被 match_string_rule 的空检查拦截，不可达）；新版 `input ?? ""` 兜底返回 false，消除潜在 throw。

## 实测确认（原 [未确认] 项）

- minimatch 10.2.6 默认选项（P0-08 附录 C-U5）：`glob:*.bin` 不匹配 `.role.bin`（dot:false 默认），`glob:.*.bin` 匹配——测试如实断言。
- minimatch v10 对畸形模式（`a{`、`[`、`a(b`、`\`、`{a,b`）**不抛异常**，按字面量编译（2026-09-24 node 实测）→ 旧版 try/catch 回退路径实际只覆盖 regex 分支；glob 分支回退不可达。测试断言该宽容行为而非虚构回退。
- 裸 `(?i)abc` 不是合法 JS RegExp → 走精确匹配回退并产生 diagnostic；合法内联 `(?i:abc)` 可用（与 P1-00 记录一致）。
