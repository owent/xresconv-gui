## 实现与证据

### 1. 预检引导器（PK05：缺 WebKit 前仍可显示诊断和安装流程）

`packaging/linux/preflight.sh`（POSIX sh，零 GUI 依赖）：

- `/etc/os-release` 识别发行版族（debian/ubuntu/fedora；不支持的发行版退出码 3 并列支持矩阵）；
- `ldconfig -p` soname 探测（webkit2gtk-4.1/JSC 4.1/gtk-3/libsoup-3），不加载库、不执行 GUI 代码；
- 就绪 → `-- <app-bin>` 时 `exec` 应用（幂等，已满足不安装/不降级）；
- 缺失 → 打印按发行版的安装命令；`--install` 或交互确认才调用包管理器（不改源、不关签名校验），安装后**复检**（不把安装器退出码当成功）；退出码 2/4 可区分。
- 随 DEB/AppImage 落位 `/usr/lib/xresconv-gui/preflight.sh`（resources 映射）。

WSL 实测：就绪路径 exit 0（WebKitGTK 4.1 已装）；注入空 ldconfig 复现缺依赖路径 → exit 2 + `sudo apt-get install -y libwebkit2gtk-4.1-0 libgtk-3-0` 指引。

### 2. 在线 DEB（bootstrap 变体）

- `tauri.linux.bootstrap.conf.json`：targets deb/rpm + 发布布局 resources + preflight 落位；`tauri.linux.offline.conf.json`：AppImage（P5-06）。
- `scripts/package-linux.ts`：os-release → targets.json distro 段映射（Debian→debian-13；不在清单即失败不猜）；组装 → tauri build → 矩阵命名 + SHA-256 边车；根脚本 `yarn package:linux`。
- WSL 构建产物（Rust release 7m04s 首建）：

```text

  sha256 c612343b39e9cada09d5edd2f5c790401e9b5a1fef0afd7adf24f1a6e835d7bc
```

- DEB 内容核验：`usr/lib/xresconv-gui/{runtime/node(126M),app/guardian/service.mjs,runtime-manifest.json,preflight.sh}`；`Depends: libwebkit2gtk-4.1-0, libgtk-3-0`（tauri 自动推导，与预检词表一致）。
- **真实安装**：`sudo dpkg -i` 成功；`/usr/bin/xresconv-gui` + `/usr/lib/xresconv-gui/` 布局与壳侧 release_layout_paths 自定位合同一致。
- **WSLg 启动冒烟**：应用进程存活（窗口经 WSLg 创建；guardian/backend 由发布布局自定位拉起）；关闭后无残留 node/guardian 进程。
