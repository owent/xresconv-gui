## 需求与设计规范

用户要求分析 [CI 第二次执行](https://github.com/owent/xresconv-gui/actions/runs/37130846883/attempts/2) 与 [Windows 失败 job](https://github.com/owent/xresconv-gui/actions/runs/37130846883/job/111231872190)，修复桌面测试和依赖缓存，并在 macOS offline 与 bootstrap 没有独立运行时差异时移除发布的 offline 包。本轮继续不发布、不移动 tag。

已核对提交 `651ea5e46c5d5214dc1fdab64d136a57344e7d8b` 的三次执行：第一次 Linux 在安装依赖时失败，Windows 第一次/第二次均因页面标题为空失败；第三次 Windows/Linux 通过。重试成功是时序证据，不是修复候选的验证结果。

| 事实 | 依据 | 实施方案 |
| --- | --- | --- |
| Windows 建会话后标题仍为空，紧随其后的握手/环境诊断与其余 UI 用例通过 | 两次日志均为 `'' !== 'xresconv-gui'`；现有标题用例未等待导航完成 | 用有界 waitUntil 等待标题后保留精确断言；补初始空标题、已就绪、永远不就绪的回归，不增加用例重跑或固定 sleep |
| Linux Yarn fetch 先报 SSL destruction / ECANCELED，再出现 settled promise onCancel 异常 | 第一次 Linux 日志；[Yarn 4.18.1](https://github.com/yarnpkg/berry/releases/tag/%40yarnpkg%2Fcli%2F4.18.1)、[官方修复 #7249](https://github.com/yarnpkg/berry/pull/7249) | packageManager 升级至 4.18.1；保留 immutable/校验，不关闭 TLS，不对所有失败盲目重试。网络仍可能失败，补丁修复取消逻辑崩溃 |
| Yarn 没有配置包缓存，desktop-e2e 也未配置 Rust 缓存；shell 的缓存目标路径错误 | ci.yml；Rust workspace 根 Cargo.toml；[rust-cache 2.9.2 config.ts](https://github.com/Swatinem/rust-cache/blob/v2.9.2/src/config.ts#L141) 将默认 target 接在指定 workspace 目录后 | 三个构建工作流统一 Yarn archive 缓存，安装后立即保存，始终执行 immutable；Rust 使用 `. -> target`，质量/桌面/发行用途分开，桌面失败也保存；缓存并固定 tauri-driver 版本 |
| macOS 两变体均为 system-only；运行时/资源组装没有独立 offline WebView | targets.json、package-cli.ts；[Tauri WebView 版本说明](https://v2.tauri.app/reference/webview-versions/) | 正式发布仅 macOS bootstrap 双架构 DMG；保留现有本地/Portable offline 命名作为兼容入口，Windows/Linux 双策略不变 |

官方依据：[WebdriverIO waitUntil](https://webdriver.io/docs/api/browser/waitUntil/)、[Yarn cacheFolder](https://yarnpkg.com/configuration/yarnrc#cacheFolder)、[GitHub cache restore/save](https://github.com/actions/cache/blob/v6.1.0/README.md)、[复用 composite action](https://docs.github.com/en/actions/tutorials/create-actions/create-a-composite-action)。actions/cache v6.1.0 已核验官方 release 与 action.yml（node24）。

发行集合由 `releaseArtifacts` / `buildMatrix` 统一生成：12 个可构建目标中，10 个目标正式发行，共 12 个产物；macOS offline 的 releaseArtifacts 为空。精确聚合仍拒绝缺件、多件、错误边车；旧历史 14 产物记录不改写。Portable 仍为 8 产物，不改既有 app.zip 命名或平台能力。

缓存只存 Yarn archives / Rust 构建依赖与工具；不存 node_modules，不以命中缓存跳过安装或验证。Yarn 缓存用锁文件、配置、平台与架构区分；缓存声明和实际 Yarn cacheFolder 必须相等。APT 使用 runner 软件源正常安装，不跨 runner 缓存系统库。Windows Edge Driver 继续按实时 WebView2 精确版本选择。

风险与回滚：等待截止仍会将真实页面故障判失败；冷缓存仍需要网络。仅删除 macOS offline 的发布产物，旧下载包不删除；回滚恢复 releaseArtifacts 分支与 macOS release matrix。Yarn 补丁与缓存配置可独立回退，但会恢复已证实的取消异常/重复下载风险。
